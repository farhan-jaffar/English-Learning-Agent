## ✨ Features

### 🗣️ Voice-First Conversational Practice
- **Record & Speak**: In-browser microphone recording with real-time audio capture
- **Immersive Roleplay Scenarios**: Practice across 4 hand-crafted conversational scenarios — *Job Interview*, *Coffee Shop Ordering*, *Airport Check-In*, and *AI Ethics Debate* — each with unique personas, difficulty levels (A2–C1), and multi-turn follow-up dialogue
- **Multi-Turn Conversations**: Engage in stateful, multi-turn dialogue sessions with an AI English Coach that responds contextually

### 🤖 Gemini-Powered AI Pipeline
- **Multimodal Speech Transcription**: Audio is transcribed directly by Gemini's multimodal API — no separate ASR service needed — with word-level timestamp interpolation
- **Linguistic Assessment**: Structured evaluation of grammar, vocabulary sophistication, and fluency using Gemini with Pydantic-validated output schemas
- **AI Coach Responses**: Contextual, pedagogically-informed conversational follow-ups generated by Gemini

### 📊 Adaptive Learning Engine
- **Bidirectional CEFR Adjustment**: Automatic promotion *and* demotion with hysteresis protection — your level goes up when you consistently excel, and recalibrates down (conservatively, requiring 5/6 sessions below threshold) if you're struggling
- **Weakness Tracking & Persistence**: Identified weaknesses (e.g., "Past Tense", "Prepositions") are tracked across sessions with frequency-based `is_recurring` flags
- **Hybrid Agent Policy**: A deterministic rule-based agent orchestrator that evaluates learner state and decides whether to *continue*, *remediate*, *ask follow-up*, *increase difficulty*, or *give feedback*
- **Adaptive Exercise Generation**: When recurring weaknesses are detected, the agent auto-generates targeted remediation exercises via Gemini

### 📈 Rich Feedback & Progress Tracking
- **Grammar Corrections**: Specific error identification with suggested corrections and explanations
- **Vocabulary Suggestions**: Sophisticated word alternatives and usage recommendations
- **Fluency Metrics**: Words per minute (WPM), pause count, average pause duration, and filler word detection — all computed deterministically from timestamps
- **Progress Dashboard**: Visual tracking of practice sessions, speaking time, and CEFR level progression
- **Recording History**: Complete history of all speech recordings with playback and analysis review

### 🔐 Authentication & Multi-Language Support
- **JWT Authentication**: Secure HTTP-only cookie-based auth with access/refresh token rotation
- **Multi-Language Ready**: Data model supports multiple target languages per user with independent CEFR tracking

## 🚀 Quick Start

### Prerequisites

- **Python 3.11+**
- **Node.js 18+** and npm
- **Redis** (local or [Upstash](https://upstash.com) free tier)
- **Google Gemini API Key** — get one free at [Google AI Studio](https://aistudio.google.com)

### 1. Clone the Repository

```bash
git clone https://github.com/farhan-jaffar/English-Learning-Agent.git
cd English-Learning-Agent
```

### 2. Backend Setup

```bash
# Create and activate virtual environment
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your GEMINI_API_KEY and other settings
```

**`.env` Configuration:**

```env
DEBUG=True
SECRET_KEY=your-random-secret-key-at-least-50-characters
GEMINI_API_KEY=your-gemini-api-key
CELERY_TASK_ALWAYS_EAGER=True          # Runs tasks synchronously (no Redis needed for dev)
CORS_ALLOWED_ORIGINS=http://localhost:5173
```

> **Tip:** Set `CELERY_TASK_ALWAYS_EAGER=True` for local development to skip Redis entirely. Tasks will run synchronously in the Django process.

```bash
# Run migrations and seed exercises
python manage.py migrate
python manage.py seed_exercises

# Start the development server
python manage.py runserver
```

### 3. Frontend Setup

```bash
cd ../frontend

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env — set VITE_API_BASE_URL=http://localhost:8000/api
```

```bash
# Start development server
npm run dev
```

Open **http://localhost:5173** — register an account and start speaking! 🎤

### 4. (Optional) Docker Services

If you want PostgreSQL and Redis locally via Docker:

```bash
cd ..  # project root
docker compose up -d
```

Then update your `backend/.env` with:
```env
DATABASE_URL=postgresql://postgres:postgrespassword@localhost:5432/english_coach
CELERY_TASK_ALWAYS_EAGER=False
CELERY_BROKER_URL=redis://localhost:6379
CELERY_RESULT_BACKEND=redis://localhost:6379
```

## 🔬 How the AI Pipeline Works

```
   🎤 User speaks into mic
          │
          ▼
   ┌──────────────┐     Upload audio to backend
   │  Recording    │────────────────────────────────┐
   │  (WebM/MP4)   │                                │
   └──────────────┘                                 ▼
                                           ┌─────────────────┐
                                           │  Celery Worker   │
                                           │  (Background)    │
                                           └────────┬────────┘
                                                    │
                          ┌─────────────────────────┼──────────────────────┐
                          ▼                         ▼                      ▼
                  ┌──────────────┐         ┌──────────────┐       ┌──────────────┐
                  │  1. Gemini   │         │ 2. Speech    │       │ 3. Gemini    │
                  │  Multimodal  │────────▶│    Metrics   │──────▶│  Linguistic  │
                  │  Transcribe  │         │  (WPM, Pause │       │  Assessment  │
                  │              │         │   Fillers)   │       │  (Structured)│
                  └──────────────┘         └──────────────┘       └──────┬───────┘
                                                                         │
                          ┌──────────────────────────────────────────────┘
                          ▼
                  ┌──────────────┐         ┌──────────────┐       ┌──────────────┐
                  │ 4. Weakness  │────────▶│ 5. CEFR      │──────▶│ 6. Agent     │
                  │   Tracking   │         │  Adjustment   │       │  Decision    │
                  │  (Recurring) │         │ (↑ Promo /    │       │ (Continue /  │
                  │              │         │  ↓ Demote)    │       │  Remediate)  │
                  └──────────────┘         └──────────────┘       └──────────────┘
```

1. **Gemini Multimodal Transcription** — Audio bytes sent directly to Gemini's multimodal endpoint; returns verbatim transcript with interpolated word timestamps
2. **Deterministic Speech Metrics** — Python-computed WPM, pause count/duration, and filler word frequency from timestamps (no LLM involved)
3. **Structured Linguistic Assessment** — Gemini evaluates grammar, vocabulary, and estimates CEFR with Pydantic schema enforcement
4. **Weakness Tracking** — New weaknesses are persisted and tracked per-language; recurring patterns flagged automatically
5. **Bidirectional CEFR Adjustment** — Promotion (4/5 qualifying sessions) and demotion with hysteresis (5/6 sessions below floor)
6. **Agent Policy Decision** — Hybrid rule engine decides next action: continue, probe with follow-up, remediate with auto-generated exercise, increase difficulty, or give summary feedback
